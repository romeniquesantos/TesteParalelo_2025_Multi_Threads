O projeto consiste em ler um arquivo Excel, armazenar os dados em uma lista e, em seguida, dividi-los em partes iguais para realizar a inserção simultânea dessas informações. 
O objetivo é utilizar o Selenium para automatizar o processo de input, rodando múltiplas instâncias em paralelo para importar os dados de forma eficiente.


Selenium 
OfficeOpenXml
